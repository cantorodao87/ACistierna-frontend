# ACistierna

WebApp para asignar unos turnos diarios concretos a diferentes trabajadores y conocer, mediante un código de colores, aquellos que podrían compartir coche.

## v0.1

- Permite asignar turnos para la mañana, tarde, con una reserva y un interventor.
- Código de colores.
- *Proyecto en fase de pruebas.*
